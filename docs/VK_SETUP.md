# Настройка сообщества VK

Шлюзу нужен **ключ доступа сообщества** с правом на сообщения и один из режимов приёма событий:
**Long Poll** (проще, без публичного URL) или **Callback API** (для продакшена).

## 1. Ключ доступа (VK_TOKEN)

1. Откройте сообщество → **Управление**.
2. **Работа с API** → **Ключи доступа** → **Создать ключ**.
3. Отметьте право **Сообщения сообщества** (при необходимости — Фото/Документы для вложений).
4. Скопируйте ключ → это `VK_TOKEN`.

## 2. Включите сообщения сообщества

- **Управление** → **Сообщения** → включите «Сообщения сообщества».
- **Настройки для бота** → включите «Возможности ботов»; при необходимости разрешите
  добавление в беседы.

## 3. Числовой id сообщества (VK_GROUP_ID)

Нужен для режима Long Poll. Способы узнать:

- В адресе сообщества вида `vk.com/club123456789` число `123456789` — это id.
- Либо через API `groups.getById` для короткого имени.

Указывайте **только число**, без `club`/`public`.

## 4. Режим A — Long Poll (для теста)

1. **Управление** → **Работа с API** → **Long Poll API**.
2. Включите Long Poll, выберите версию API (та же, что в `VK_API_VERSION`, например `5.199`).
3. На вкладке **Типы событий** включите **Входящее сообщение** (`message_new`).
4. В `.env`: `VK_MODE=longpoll`, `VK_TOKEN=...`, `VK_GROUP_ID=...`.

Публичный URL не требуется — шлюз сам опрашивает серверы VK.

## 5. Режим B — Callback API (для продакшена)

1. Поднимите шлюз на публичном **HTTPS** (см. [INSTALL.md](INSTALL.md), reverse-proxy).
2. **Управление** → **Работа с API** → **Callback API**.
3. Версия API — как в `VK_API_VERSION`.
4. **Типы событий** → включите **Входящее сообщение** (`message_new`).
5. Поле **Секретный ключ** → задайте значение → это `VK_CALLBACK_SECRET`.
6. Поле **Строка, которую возвращает сервер** (подтверждение) → это `VK_CONFIRMATION`.
   > Важно: запустите шлюз с этим значением **до** нажатия «Подтвердить», чтобы VK получил
   > правильный ответ от `GET/POST https://<домен>/vk/callback`.
7. Укажите адрес сервера `https://<домен>/vk/callback` и нажмите **Подтвердить**.
8. В `.env`: `VK_MODE=callback`, `PUBLIC_URL=https://<домен>`, `VK_CONFIRMATION=...`,
   `VK_CALLBACK_SECRET=...`.

## Заметки

- Скачивание **видео** VK ограничивает — шлюз пересылает ссылку/заголовок текстом.
- Исходящие фото/файлы шлюз загружает на серверы VK автоматически (`getMessagesUploadServer`).
- Каждое исходящее сообщение отправляется с уникальным `random_id` (дедуп на стороне VK).
