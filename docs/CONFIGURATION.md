# Конфигурация (переменные окружения)

Все настройки задаются через переменные окружения (файл `.env` локально или `env_file` в Docker).
Валидация — `src/config.ts` (zod), при ошибке шлюз не стартует и печатает причину.

## Шлюз

| Переменная          | Обяз.        | По умолчанию | Описание                                                    |
| ------------------- | ------------ | ------------ | ----------------------------------------------------------- |
| `NODE_ENV`          | нет          | `production` | `development` включает читаемые логи (pino-pretty)          |
| `PORT`              | нет          | `3000`       | Порт HTTP-сервера                                           |
| `PUBLIC_URL`        | для callback | —            | Публичный HTTPS-адрес шлюза, напр. `https://gw.example.com` |
| `LOG_LEVEL`         | нет          | `info`       | `trace`/`debug`/`info`/`warn`/`error`/`fatal`               |
| `MAX_ATTACHMENT_MB` | нет          | `50`         | Лимит размера скачиваемых/пересылаемых файлов (МБ)          |

## VK

| Переменная           | Обяз.        | По умолчанию | Описание                                       |
| -------------------- | ------------ | ------------ | ---------------------------------------------- |
| `VK_MODE`            | нет          | `longpoll`   | `longpoll` или `callback`                      |
| `VK_TOKEN`           | **да**       | —            | Ключ доступа сообщества с правом «Сообщения»   |
| `VK_GROUP_ID`        | для longpoll | —            | Числовой id сообщества                         |
| `VK_API_VERSION`     | нет          | `5.199`      | Версия VK API                                  |
| `VK_CONFIRMATION`    | для callback | —            | Строка подтверждения Callback API              |
| `VK_CALLBACK_SECRET` | нет          | —            | Секрет Callback API (если задан — проверяется) |

## Chatwoot

| Переменная                | Обяз.  | По умолчанию | Описание                                                    |
| ------------------------- | ------ | ------------ | ----------------------------------------------------------- |
| `CHATWOOT_URL`            | **да** | —            | Base URL установки, без слэша на конце                      |
| `CHATWOOT_ACCOUNT_ID`     | **да** | —            | Числовой id аккаунта                                        |
| `CHATWOOT_TOKEN`          | **да** | —            | Application API access token (заголовок `api_access_token`) |
| `CHATWOOT_INBOX_ID`       | **да** | —            | Числовой id API-инбокса для VK                              |
| `CHATWOOT_WEBHOOK_SECRET` | нет    | —            | Секрет для проверки HMAC-подписи вебхуков                   |

## Прочее

| Переменная  | Обяз. | По умолчанию | Описание                                       |
| ----------- | ----- | ------------ | ---------------------------------------------- |
| `REDIS_URL` | нет   | —            | URL Redis для дедуп-кэша; пусто — кэш в памяти |

## Условия валидации

- `VK_MODE=longpoll` → требуется `VK_GROUP_ID`.
- `VK_MODE=callback` → требуются `VK_CONFIRMATION` и `PUBLIC_URL`.

Пустые строки трактуются как «не задано». Числовые значения приводятся из строк автоматически.
